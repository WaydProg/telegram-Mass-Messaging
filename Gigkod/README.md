# Рассылка Gigkod

## Запуск

```sh
python3 sender.py
```

Команда проверит `users.txt` и покажет адресатов и текст из `template.txt`. Для предпросмотра достаточно Python 3.

Для публикации установите зависимость в отдельное окружение и задайте `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` своего приложения с [my.telegram.org](https://my.telegram.org/apps). При первом запуске авторизуйтесь в своём Telegram. По умолчанию скрипт создаст файл `gigkod.session` рядом с собой. Путь к своей сессии можно передать через `TELEGRAM_SESSION`.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python sender.py --send
```

Один запуск проходит по списку один раз. Скрипт проверяет, что каждый адрес ведёт в публичную группу, в которой вы состоите. Сообщения в группах с темами размещайте вручную в нужной теме. При ограничении на отправку скрипт остановится. Журнал `sent.sqlite3` хранит опубликованные сообщения и попытки с неизвестным результатом. Сохраняйте один и тот же журнал и имя кампании при повторном запуске. Если результат попытки неизвестен, сначала проверьте историю чата.

Для другого текста или согласованного списка предусмотрены параметры `--template` и `--chats`. Используйте `--campaign` для отдельной кампании.
